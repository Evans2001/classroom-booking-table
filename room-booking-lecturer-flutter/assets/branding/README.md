# App icon

`app-icon.png` is the master artwork, generated with the built-in imagegen tool.
Android launcher PNGs are resized copies in each `mipmap-*` density directory.
Android 8 and later use an adaptive icon with burgundy background and inset artwork.

Generation prompt:

Create a polished square Android launcher icon for a university classroom booking app. Flat bold graphic logo, a clever fusion of a classroom doorway and a calendar, with a small golden checkmark suggesting a reserved room. Deep burgundy #5C2C30 full bleed solid background, warm ivory main symbol, golden yellow #EAB308 accent. Distinctive elegant geometric silhouette, thick clean strokes, very legible at 48 pixels. Center all symbol artwork within central 60 percent of canvas so circular Android masks cannot clip it. Square 1024 by 1024 composition, no rounded outer corners, no border, no letters, no text, no watermark, no mockup, no shadows outside symbol. One single final icon.
